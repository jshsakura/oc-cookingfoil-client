# CookingFoil brand assets

`cookingfoil-readme-256.png` is the maintainer-supplied 256×256 README logo,
including the butter mark, wordmark and background. This is the original PNG;
preserve its bytes and use display dimensions when a smaller rendering is needed.

Use it for repository identity. Game covers without artwork use the app’s own
first-letter tiles, never the brand logo. Published interface screenshots use English.
