# 기능 안내

[전체 안내](README.ko.md) · [시작하기](GETTING-STARTED.ko.md) · [English](FEATURES.md)

CookingFoil은 직접 운영하는 서버의 파일을 본체에서 사용하는 클라이언트입니다.
서버가 메타데이터와 지원 기능을 알려 주고, 클라이언트는 선택, 로컬 기록과 설치를 담당합니다.

## 둘러보기와 설치

홈 목록, 검색, 필터와 정렬로 게임을 찾습니다. 상세 화면에서 본편, 업데이트와 DLC를 골라
SD 카드나 본체 저장 공간에 설치합니다. HTTP를 통한 NSP·NSZ·XCI·XCZ 설치에는 CyberFoil 엔진을 사용합니다.

여러 서버를 켜면 목록을 함께 보여 주고 항목의 원래 서버를 기억합니다. 같은 항목을 여러
서버에서 제공하면 받을 곳을 고릅니다. 설치된 버전과 서버의 버전을 비교해 업데이트를 확인합니다.

## 다운로드와 복구

대기열과 완료·실패·취소 기록을 `cookingfoil.db`에 보관합니다. 지원되는 설치는 중단 지점과
범위 정보를 남겨 처음부터 다시 받지 않고 이어 갑니다. 실행이 끊긴 뒤에는 다음 실행에서
이어서 받을지 묻습니다. 연결 복구와 재시도는 화면 그리기와 다른 스레드에서 처리하고,
받는 동안에는 본체가 절전 모드로 들어가지 않습니다.

이어 받기는 다운로드 종류와 서버에 같은 파일이 남아 있는지에 따라 달라집니다.
서버나 파일이 바뀌면 다시 시도해야 할 수 있습니다. 서버가 지정한 직접 다운로드 주소가
실패했다고 해서 공개 주소로 임의 전환하지 않습니다.

## 홈브루

서버가 제공하는 NRO와 앱 폴더를 설치합니다. 서버의 콘텐츠 해시와 로컬 배치 기록을 비교해
설치 여부와 업데이트를 표시합니다. 폴더 설치는 파일별 해시를 확인하고 다른 파일을 받습니다.
단일 파일은 다운로드와 확인이 끝난 뒤 기존 파일을 교체합니다.

지원되는 항목은 HOME 메뉴 바로가기를 만들 수 있습니다. 삭제할 때는 배치 기록을 따라가므로
관련 없는 파일은 건드리지 않습니다. GitHub 릴리스 추적은 서버가 담당하고, 클라이언트는
서버가 제공하는 빌드를 설치합니다.

## 세이브

본체 세이브, 서버 세이브와 Dropbox 백업을 나누어 보여 줍니다. 사용자별 로컬 백업과 복원,
서버 세이브 가져오기, Dropbox 리비전 업로드와 다운로드를 지원합니다. 본체 세이브에 접근하는
작업에는 해당 홈브루 권한이 필요합니다.

로컬 백업은 `sdmc:/switch/oc-save-keeper/`와 save-keeper의 폴더·메타데이터 형식을 사용합니다.
일반 백업은 게임당 다섯 개를 보관합니다. 복원 전 만드는 되돌림용 복사본은 따로 세어
사용자가 만든 백업을 밀어내지 않습니다. 삭제한 백업은 공용 휴지통 구조로 옮기며,
복원할 때 계정 세이브와 기기 공용 세이브의 종류를 확인합니다.

Dropbox는 호환 서버의 QR 로그인 브리지를 사용합니다. 인증이 끝나면 본체가 Dropbox와 직접
토큰을 교환하고 백업을 전송합니다. 연결만 했다고 원격 세이브를 자동 적용하지 않습니다.
사용자가 백업을 골라 작업을 확인합니다. save-keeper와 Dropbox 백업을 공유하려면 두 브리지가
같은 Dropbox 앱을 사용해야 합니다.

## 패치

서버의 게임 패치를 받아 켜거나 끄고 삭제합니다. LayeredFS의 `romfs`·`exefs`, 치트,
IPS `exefs_patches`와 FPSLocker 패치를 지원합니다. FPSLocker 패치에는 FPSLocker가 별도로 필요합니다.

배치 기록으로 앱이 관리하는 파일을 구분하고, 같은 파일을 놓으려는 패치의 충돌을 확인합니다.
치트는 빌드 ID별로 합치고 기존 치트를 앞에 보관합니다. 모두 끄면 원래 파일을 복원합니다.
파일 이동 전에 계획을 기록하므로 작업이 끊겨도 다음 실행에서 이어 마칠 수 있습니다.
패치를 바꾼 뒤에는 게임을 다시 실행합니다.

## 레트로 라이브러리

호환 서버가 제공하는 시스템 목록, 검색, 게임 변형과 다운로드 묶음을 사용합니다.
서버의 RetroArch 팩, 게임 파일과 HOME 메뉴 바로가기를 받고, 설정되어 있으면
RetroAchievements 정보를 표시합니다.

이 저장소에는 ROM, BIOS나 RetroArch가 없습니다. 사용할 권리가 있는 콘텐츠와 필요한
서버 팩을 직접 준비합니다.

## PC 연결 (MTP)

USB 케이블로 SD 카드를 PC에서 열어 파일을 보고 옮깁니다. 설정의 **MTP 모드로 PC와 연결**을
누른 뒤 케이블을 꽂습니다. B를 누르거나 케이블을 뽑으면 연결을 끊습니다. Nintendo, emuMMC처럼
민감한 폴더는 바꿀 수 없습니다. 앨범에서 실행한 애플릿 모드에서는 메모리가 부족해 연결할 수
없으므로 HOME 메뉴 바로가기로 실행합니다.

연결을 끊을 때 다 옮기지 못한 파일과 Mac이 남긴 `._*`·`.DS_Store` 파일을 지웁니다.

- **Windows**: 파일 탐색기에 장치로 나타납니다. 따로 설치할 것은 없습니다.
- **Mac**: macOS에는 MTP 파일 관리 기능이 없으므로 [OpenMTP](https://openmtp.ganeshrvel.com/)를
  사용합니다. 설정에서 Kalam 모드를 켭니다.

**Mac에서 연결되지 않을 때**: 미리보기, 사진, 이미지 캡처가 열려 있으면 macOS가 본체를
카메라로 잡고 놓아 주지 않아 OpenMTP가 접근하지 못합니다. 세 앱을 모두 종료하고 케이블을
다시 꽂습니다. `ptpcamerad` 프로세스는 종료해도 바로 다시 실행되므로 앱을 닫아야 합니다.

## 관리

설치된 게임과 세이브를 관리합니다. 남은 파일 정리는 확인을 거쳐, 설치된 타이틀이 참조하지
않는 콘텐츠와 끝나지 않은 설치가 만든 placeholder를 지웁니다. 삭제 확인의 기본 선택은 취소입니다.

호환 서버가 앱 빌드를 제공하면 설정에서 클라이언트를 업데이트할 수 있습니다.
받은 빌드를 확인하고 준비한 뒤 다음 실행 때 앱을 교체합니다. 새 버전이 보인다는 것만으로
설치가 끝난 것은 아닙니다.

## 입력과 언어

터치와 컨트롤러가 같은 화면을 사용합니다. 한국어·영어·일본어·중국어를 지원하며 선택한 언어를
기억합니다. 호스트 미리보기도 같은 UI를 예제 데이터나 실제 서버로 실행하지만,
본체에서만 가능한 작업은 호스트에서 대체 구현을 사용합니다.
